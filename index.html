Real shared posts, comments and live notifications will work after setup. Push alerts while the site is closed also require Firebase Cloud Messaging.

How to make it live

  1. Create a Firebase project at Firebase Console.
  2. Enable Authentication (Google or email), Firestore Database and Storage.
  3. Register a Web App and copy its Firebase configuration.
  4. Save posts/comments in Firestore and media files in Storage.
  5. Use Firebase Cloud Messaging or an email service for notifications; configure secure rules before publishing.
  6. Deploy the site on GitHub Pages or Firebase Hosting and test with two accounts/devices.
